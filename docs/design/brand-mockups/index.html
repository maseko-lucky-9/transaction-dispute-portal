Dispute Portal brand directions

Five design directions for the Capitec rebrand, each across the same six pages and the same sample data. Open any page, then use the dark bar at the bottom to switch direction on that page (or press the left and right arrow keys), jump between pages and flip light and dark.

Pick one direction, or name the parts you want from several, for example the header from A with the table from C.

What every direction keeps, so the chosen one can be built as shown

  • No counts on the filter links and no totals on Home: the API pages results and does not return totals.
  • The Capitec logo appears once, in the header, on a white tile (the supplied file has a white background).
  • The signed-out page's main heading reads "Sign in", and it has a single Sign in button.
  • Home links are named My transactions, My disputes and Review queue, one each.
  • The Status dropdown stays next to the status filter links.
  • The agent progress stepper uses icons only; the status word lives in the pill beside it.
  • The sign-in page is Keycloak's own login form, restyled: same fields, same order, new colours and logo.
  • Royal Blue is used for fills and large text only; it is too light for small text on white.
